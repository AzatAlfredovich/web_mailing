# Сервис управления рассылками
 
Сервис управления рассылками, клиентами, сообщениями и пользователями.  
Система поддерживает роли пользователей, контроль доступа, кастомные Django-команды, собирает статистику по попыткам отправки.

## Основной функционал

### Пользователи
- Регистрация с подтверждением по email, авторизация, редактирование профиля и смена пароля.
- Кастомная модель `CustomUser`.
- Наследование от Django `AbstractUser`.
- Поддержка фото, телефона, страны.
- Роль **Менеджер** (группа «Менеджеры») с расширенными правами.
- Возможность заблокировать/разблокировать других пользователей.

### Клиенты
- Создание, редактирование и удаление клиентов.
- Каждый клиент привязан к владельцу.
- Менеджеры видят всех клиентов.
- Пользователь - только своих клиентов.

### Сообщения
- Шаблоны писем (заголовок + содержание).
- Привязка к владельцу.
- Менеджеры видят все сообщения без права удаления и редактирования.

### Рассылки
- Настройка даты начала и конца рассылки.
- Привязка к сообщению и списку клиентов.
- Поле `is_active` — возможность включать и отключать рассылку.
- Кнопка ручной отправки рассылок через кастомную команду и интерфейс.
- Менеджеры видят все рассылки и могут лишь отключать их.

### Попытки отправки
- История попыток (успешно/безуспешно).
- Показывается статус в карточке рассылки.

## Кастомные Django-команды

### 1. Отправка рассылок вручную
`python manage.py send_mailing`

Запускает проверку активных рассылок и создает записи Attempt.

### 2. Создание менеджерской группы с правами и одного менеджера
`python manage.py create_manager_group`

Создаёт группу **Менеджеры**, менеджера и назначает права:
- просматривать всех клиентов
- просматривать все сообщения
- просматривать все рассылки
- отключать рассылки
- блокировать пользователей

## Права доступа

Реализованы на трёх уровнях:

### 1. **Модельные права Meta**
```python
permissions = (
    ('view_recipient', 'Может просматривать получателей'),
)
```
### 2. **Проверки в представлениях (views)**

Менеджер видит всё.

Пользователь - только своё.

### 3. **Логика в шаблонах**
```
{% if user.is_manager %}
    показывает тут кнопку
{% endif %}
```
## Реализация

 - Переход на email вместо username - переопределение аутентификации Django.

 - Страница отчётов выводит статистику по успешным, безуспешным рассылкам и в % соотношении. 

 - Кэширование `HomeView` - чтобы снизить нагрузку.

 - Загрузка фото пользователей из `/media/`.

## Установка и запуск
### 1. Клонировать репозиторий:
```
git clone https://github.com/AzatAlfredovich/web_mailing.git
```
### 2. Создать .env по шаблону:
`.env.sample`
### 3. Установить зависимости:
`pip install -r requirements.txt`
### 4. Применить миграции:
`python manage.py migrate`
### 5. Создать группу менеджеров:
`python manage.py create_manager_group`
### 6. Запустить сервер:
`python manage.py runserver`
